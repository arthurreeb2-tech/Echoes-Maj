# Echoes-Maj

Canal de mise à jour d'[Echoes](https://github.com/arthurreeb2-tech/Echoes).

Chaque version publiée sur Echoes est recopiée ici toutes les heures par `.github/workflows/mirror.yml` (avec contrôle des empreintes SHA-256). Les machines Echoes y cherchent leurs mises à jour, avec Echoes en secours. Pour recopier tout de suite : onglet Actions, « Recopie des versions d'Echoes », Run workflow.

Ce dépôt doit rester public.
